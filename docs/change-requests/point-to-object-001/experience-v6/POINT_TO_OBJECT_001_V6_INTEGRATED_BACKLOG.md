## Dependency and gate logic

1. No ranking implementation before comparable GeoContext coverage, versioned metrics/method, missing-data policy and a passing DecisionRecord gate.
2. No authoritative planning or compliance claim before licensed jurisdiction-specific data/rules and professional validation.
3. No proprietary generation-provider dependency before identical bake-off, written API/OEM/output rights, security review and three-year TCO.
4. No hosted persistence before approved schema/migration, tenant identity, RLS personas, retention/deletion and audit evidence.
5. No report or dashboard recomputation; both render the immutable DecisionRecord.
6. No merge or Production promotion before separate founder approval and full release process.
